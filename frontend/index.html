🧠 Judge Criteria: How GhostWriter Outperforms

Most AI apps are simple chat wrappers. GhostWriter implements an autonomous four-agent coordination loop with AST syntax verification:

1. Vision Agent (Spatial Grounding)
Identifies visual boundaries, shapes, and OCR text labels without hallucinating extraneous design fluff.
2. Layout Agent (AST Constructor)
Normalizes rough sketch lines into an Abstract Syntax Tree representing parent-child component hierarchies.
3. Code Synthesizer Agent
Transforms the AST into production React Native/Expo code with typed useState hooks and styling.
4. Self-Healing Compiler Agent
Catches missing packages or deprecated syntax, self-correcting the code before it reaches the phone.
